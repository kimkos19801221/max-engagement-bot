# MAX Engagement Bot

Отдельный проект engagement-бота для комментариев в публичных каналах MAX.

Цель: поднимать активность в комментариях без репутационного риска. Бот умеет
работать в безопасном dry-run режиме: анализирует комментарии подписчиков,
применяет лимиты и правила безопасности, затем пишет черновики действий в
Supabase, не публикуя их наружу.

## Что уже есть

- `docs/product-spec.md` - продуктовая спецификация и правила безопасности.
- `supabase/migrations/001_max_engagement_bot.sql` - схема Supabase.
- `src/max-engagement/safety.ts` - решение, можно ли отвечать и с каким уровнем подкола.
- `src/max-engagement/content-safety.ts` - стоп-триггеры, вопросы и базовая классификация текста.
- `src/max-engagement/repository.ts` - доступ к таблицам Supabase.
- `src/worker.ts` - dry-run worker для обработки новых комментариев.
- `docker-compose.timeweb.yml` - изолированный запуск worker-контейнера в Timeweb.
- `docs/timeweb-deploy.md` - правила размещения без вмешательства в DecorRent.

## Настройка

Создайте `.env.local` по примеру `.env.example`.

Для воркера нужен серверный ключ:

```bash
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SECRET_KEY=your-service-role-or-secret-key
```

`SUPABASE_PUBLISHABLE_KEY` подходит для фронтенда, но для серверного воркера
нужен секретный ключ, иначе RLS не даст читать и писать таблицы.

## Команды

```bash
npm install
npm run seed:test
npm run typecheck
npm test
npm run dev:dry-run
npm run admin:local
```

`npm run dev:dry-run` делает один проход:

1. Берет включенные каналы из `max_engagement_channels`.
2. Находит новые комментарии подписчиков в `max_engagement_comments`.
3. Проверяет режим, лимиты, стоп-триггеры и классификацию поста.
4. Создает запись в `max_engagement_bot_actions` со статусом `draft`.

`npm run admin:local` открывает локальную панель ревью на
`http://127.0.0.1:4317`. Это только локальный инструмент: перед размещением
админ-панели в Timeweb нужно отдельно добавить авторизацию и согласовать любые
порты/Nginx-настройки, чтобы не задеть DecorRent.

Локальная панель уже закрывает базовые админ-сценарии из ТЗ:

- ревью черновиков;
- журнал всех подколов;
- фильтр "только уровень 3";
- быстрое "удалить свой комментарий" для репутационных инцидентов;
- остановка треда;
- базовая аналитика по росту комментариев/реакций и индексу токсичности.
- редактирование настроек канала: режим, тип паблика, имя/подпись бота,
  уровень подкола, лимиты, рабочее время, dry-run и подтверждение риска уровня 3.
- загрузка и просмотр примеров стиля администратора: обычные сообщения,
  удачные подколы и примеры "перебор" из ручного ввода, `.txt`, `.csv`, `.json`.

## Timeweb Cloud

Бот размещается отдельно от DecorRent. Локальная Docker-конфигурация не
публикует порты наружу и не требует Nginx:

```bash
cp .env.timeweb.example .env.timeweb
docker compose -f docker-compose.timeweb.yml up -d --build
```

Перед изменением общих настроек сервера, Nginx, PM2, сетей, портов, домена,
GitHub Actions или Supabase-проекта DecorRent нужно сначала получить отдельное
подтверждение владельца.
