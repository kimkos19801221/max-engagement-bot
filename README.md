# MAX Engagement Bot

Отдельный проект engagement-бота для комментариев в пабликах MAX.

Цель: повышать активность в комментариях без репутационного риска: отвечать,
инициировать легкие комментарии в режиме "оживление", учитывать тип паблика и
жестко отключать подколы под чувствительными темами.

## Стартовый состав

- `docs/product-spec.md` - продуктовая спецификация и правила безопасности.
- `supabase/migrations/001_max_engagement_bot.sql` - схема БД.
- `src/max-engagement/types.ts` - типы режимов и решений.
- `src/max-engagement/safety.ts` - чистая логика принятия решения.

## Проверка

```bash
npm install
npm run typecheck
```
